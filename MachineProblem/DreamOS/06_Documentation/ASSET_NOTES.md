# Asset notes

All `Concept`/`Design` images are rasterized AI-generated mockups. They are not transparent UI components or sprite sheets with independent layers. The window crops may contain neighboring decorative elements. Recreate the functional interfaces with native WinForms controls and GDI+ drawing. Decorative source rectangles can be drawn from these PNGs; do not use the screenshot text/fields as interactive controls. The original guide girl JPEG has a white background; keep it as-is or carefully create a transparent cutout by hand. Do not claim transparency is present.

The originals are included solely as user-provided project references; preserve their attribution and avoid redistributing third-party material.

This is a **native C# WinForms** visual reference pack. Recreate all windows as actual Windows Forms controls, not browser code.

The implementation packages the original artwork through both project files. See `DreamOS.WinForms/Controls/Artwork.cs` for source rectangles and `../../README.md` for the runtime styling and Windows validation notes. Original files remain unchanged; the original JPEG backdrop is masked only during rendering.
