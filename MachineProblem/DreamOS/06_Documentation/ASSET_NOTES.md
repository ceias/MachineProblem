# Asset notes

All `Concept`/`Design` images are rasterized AI-generated mockups. They are not transparent UI components or sprite sheets with independent layers. The window crops may contain neighboring decorative elements. For production use, redraw functional interfaces with CSS/React. The original guide girl JPEG has a white background; keep it as-is or carefully create a transparent cutout by hand. Do not claim transparency is present.

The originals are included solely as user-provided project references; preserve their attribution and avoid redistributing third-party material.

This is a **native C# WinForms** visual reference pack. Recreate all windows as actual Windows Forms controls, not browser code.
